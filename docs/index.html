Installation & Automatic Updates

INSTALL

Drag-and-drop macOS Installer

  1. Download 1550nm-*-macos-arm64.dmg above and open it.
  2. Drag 1550nm.app into the Applications folder.
  3. Launch 1550nm — it is signed and notarized by Apple, so Gatekeeper verifies it cleanly.
SELF-UPDATE

Permission-Based In-App Updates

  1. On launch (or by pressing U / clicking the version pill), 1550nm checks GitHub Releases.
  2. When a newer version is published, an in-app modal shows the release notes and asks for permission.
  3. Clicking Install & Relaunch verifies the SHA-256 hash and Apple Developer signature before swapping the bundle.
