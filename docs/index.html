Installation & Automatic Updates

MACOS INSTALL

Signed & Notarized Installer

  1. Download QN-Bench-*-macos-universal.dmg above and open it.
  2. Drag QN Bench.app into the Applications folder.
  3. Launch QN Bench — signed and notarized by Apple for Gatekeeper.
WINDOWS INSTALL

Windows 10/11 (x64)

  1. Download QN-Bench-*-windows-x64-setup.exe (or extract the portable .zip).
  2. Because the Windows build is unsigned, if SmartScreen appears click More info → Run anyway.
  3. Installs per-user (no admin required) so in-app updates work cleanly.
SELF-UPDATE

Permission-Based Updates

  1. On launch (or via U / the version pill), QN Bench checks GitHub Releases.
  2. When an update is available, a modal displays the release notes and asks for permission.
  3. Clicking Install & Relaunch verifies SHA-256 (plus Apple signature on macOS) before swapping.

16 Quantum Networking Challenges + Free-Build Sandbox

LEVELS 1–3

Transduction & Long-Haul

Convert 780nm trapped-ion photons to 1550nm using a PPLN QFC, strip Raman pump noise with VBG filters, steer around cryostats, and restore fidelity with Quantum Memory.

LEVELS 4–8

HOM Swapping, WDM & PMD

Match picosecond arrival timing at a 50:50 Bell-State Measurement beam splitter, multiplex perpendicular beams through shared filters, survive lit telecom fiber, and fix polarization drift with Half-Wave Plates.

LEVELS 9–11

Distillation, Hybrid & Satellites

Purify noisy pairs to 95% for fault-tolerant QPUs, bridge 637nm Diamond NV and 780nm Ion nodes, and lock wavefronts with Adaptive Optics through atmospheric turbulence.

LEVELS 12–16 & SANDBOX

QKD, Multi-Hop Repeaters & Free-Build

Run BB84/E91 QKD + live FIPS-197 AES-256, chain heralded multi-hop quantum repeaters (L15), lock an orbital satellite E91 link past Eve (L16), or build & share custom JSON benches in Sandbox Mode.
